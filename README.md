# אתגר הקוד של עכו

משחק תחרותי למעקב אחר קוד (לולאות ורקורסיה) לצוותי תיכון, ליום שיא במדעי המחשב בעכו.

## מבנה

| נתיב | תפקיד |
|---|---|
| `public/` | הדף (HTML/CSS/JS). אינו מכיל את התשובות הנכונות |
| `api/start.js` | פתיחת משחק לצוות, מחזיר את השאלות עם אפשרויות מעורבבות |
| `api/answer.js` | בדיקת תשובה וניקוד בשרת. בסיום — שמירה בטבלת המובילים |
| `api/scores.js` | טבלת המובילים |
| `api/admin.js` | כלי מארגנים (מוגן בסיסמה): מחיקה, ניקוי, ייבוא תוצאות מהגרסה המקומית |
| `lib/questions.js` | מאגר השאלות, התשובות וההסברים (בשרת בלבד) |

## הגדרה ב-Vercel

1. **Storage → Upstash Redis** — חברו מסד נתונים לפרויקט (משתני הסביבה `KV_REST_API_URL` ו-`KV_REST_API_TOKEN` נוספים אוטומטית).
2. **Settings → Environment Variables** — הוסיפו `ADMIN_PASSWORD` (סיסמת המארגנים).
3. בצעו Redeploy כדי שהמשתנים ייכנסו לתוקף.

## עבודה בלי רשת

הקובץ `akko-cs-challenge.html` (הגרסה המקומית) עובד במחשב בלי אינטרנט. אחרי האירוע אפשר לייצא ממנו גיבוי JSON
ולייבא אותו לטבלה המקוונת דרך "כלי מארגנים → ייבוא תוצאות מהגרסה המקומית".
